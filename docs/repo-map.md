# แผนที่ repo

ไฟล์นี้เป็นแหล่งความรู้เดียวที่ agent ทุกตัวใช้ระบุว่างานอยู่ระบบย่อยใด ต้องอัปเดตใน PR เดียวกับที่เปลี่ยนโครงสร้าง

| ระบบย่อย | โฟลเดอร์ | หน้าที่ | ผู้ใช้ | พึ่งพา |
|---|---|---|---|---|
| เว็บและ API | `apps/web` | หน้าจอรับเรื่อง คัดแยก ออกแบบ อนุมัติ รายงาน และ API | Helpdesk, SA, ผู้บริหาร, ผู้ดูแลระบบ | db, github, agents |
| ฐานข้อมูล | `packages/db` | โครงสร้างตาราง migration และการเข้าถึงข้อมูล | ระบบย่อยอื่น | ไม่มี |
| เชื่อม GitHub | `packages/github` | GitHub App, สร้าง issue, ส่งไฟล์ที่อนุมัติ, รับ webhook | ระบบย่อยอื่น | db |
| Agent | `packages/agents` | Agent ออกแบบ คำสั่งของ agent และการสั่งงาน agent วิเคราะห์โค้ด | SA ผ่านหน้าเว็บ | db, github |
| เอกสาร | `docs` | intent, spec, policy, แนวทางหน้าจอ | ทุกคนและ agent | ไม่มี |

## กฎการพึ่งพา

- `packages/db` ไม่เรียกระบบย่อยอื่น
- `packages/*` ไม่เรียก `apps/web`
- งานที่แตะมากกว่าหนึ่งระบบย่อยต้องระบุทุกตัวใน spec

## สิ่งที่ยังไม่มี

โค้ดของทุกระบบย่อยยังไม่ถูกสร้าง ตารางนี้คือโครงสร้างเป้าหมาย
