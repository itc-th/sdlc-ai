# ขั้นตอนทำงานหนึ่งเรื่อง

ระหว่างที่ SDLC-AI ยังไม่พร้อมใช้ ทีมทำขั้นตอนนี้ด้วย GitHub และ Claude Code โดยตรง

| ขั้น | ใครทำ | ผลลัพธ์ | ผู้อนุมัติ |
|---|---|---|---|
| 1. รับเรื่อง | ใครก็ได้ | GitHub issue จากฟอร์ม | ไม่มี |
| 2. คัดแยก | SA | label ประเภท ระบบย่อย ระดับความเสี่ยง | SA |
| 3. intent | SA กับ agent (`/intent <เลข issue>`) | `intent.md` | SA |
| 4. spec | SA กับ agent | `spec.md` | ตามระดับความเสี่ยง |
| 5. แผน | programmer กับ agent | แผนการแก้โค้ดใน issue | programmer |
| 6. พัฒนา | programmer กับ agent | PR | ผู้ที่ไม่ใช่ผู้เปิด PR |
| 7. ปิด | SA | ยืนยันตามเกณฑ์ว่าเสร็จ และเพิ่มเคสทดสอบถ้าเป็น bug | SA |

## ผู้อนุมัติ spec ตามระดับความเสี่ยง

- ต่ำ: SA
- กลาง: SA และเจ้าของ policy
- สูง: SA เจ้าของ policy และ tech lead

## ตัวชี้วัดที่เก็บตั้งแต่เรื่องแรก

เวลาจากเปิด issue ถึง intent อนุมัติ, จำนวนรอบแก้ spec, เวลาจาก spec อนุมัติถึงเปิด PR, เวลารอรีวิว PR
