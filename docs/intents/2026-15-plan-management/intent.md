- ผู้ร่าง: Claude (agent)  วันที่: 2026-11-17
- สถานะ: อนุมัติแล้ว  ผู้อนุมัติ: sakchai (2026-11-17)

## ปัญหาและที่มา
กระบวนการใน process.md ขั้น 5 ระบุว่า programmer กับ agent เสนอแผนการแก้โค้ดแล้วให้ programmer อนุมัติก่อนเขียนโค้ด แต่ยังไม่มีหน้าจอสำหรับขั้นตอนนี้ ตอนนี้ทำผ่าน chat/issue comment

## ทำไมต้องทำ
ถ้าไม่มีหน้าจอ แผนการแก้โค้ดไม่ถูกบันทึกอย่างเป็นทางการ ไม่มี audit trail และสถานะ issue ไม่เปลี่ยนอัตโนมัติ

## ผู้ใช้ที่เกี่ยวข้อง
- Programmer — เสนอและอนุมัติแผน (~5-10 คน)
- SA — ดูแผนที่เสนอ

## ขอบเขต
- ทำ:
  - เพิ่มตาราง plans ใน DB (issueId, authorId, content, status)
  - หน้าสร้าง/แก้ไข/ดูแผนจาก issue detail (หลัง spec approved)
  - ระบบอนุมัติ/ปฏิเสธแผน พร้อม comment
  - อัปเดต issue.status → 'in_progress' เมื่ออนุมัติแผน
  - บันทึก audit log
- ไม่ทำ:
  - ยังไม่เชื่อม PR tracking
  - ยังไม่ทำ auto-generate plan จาก agent

## เกณฑ์ว่าเสร็จ
- [ ] สร้างแผนจากหน้า issue (หลัง spec approved) ได้
- [ ] แก้ไขแผนที่เป็น draft ได้
- [ ] อนุมัติ/ปฏิเสธแผนได้ พร้อม comment
- [ ] issue.status อัปเดตเป็น in_progress เมื่ออนุมัติแผน
- [ ] บันทึก audit log ทุกการกระทำ
- [ ] `pnpm build` และ `pnpm lint` ผ่าน
