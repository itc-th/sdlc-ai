## ปัญหาและที่มา
ระบบมีหน้าจัดการ issue, intent, spec แล้ว แต่ยังไม่มีหน้าภาพรวมให้ผู้บริหารเห็นสถานะงานทั้งหมดในที่เดียว ต้องเข้าไปดูรายการ issue ทีละรายการ

## ทำไมต้องทำ
ผู้บริหารต้องการเห็นภาพรวมเร็ว — จำนวน issue ตามสถานะ ประเภท ระดับความเสี่ยง — เพื่อจัดลำดับงานและวางแผนทรัพยากร

## ผู้ใช้ที่เกี่ยวข้อง
- ผู้บริหาร — ดูภาพรวมงาน (~2-3 คน)
- SA — ดูปริมาณงานค้าง

## ขอบเขต
- ทำ:
  - หน้า `/dashboard` แสดงจำนวน issue แบ่งตาม status, type, risk_level
  - แสดง issue ล่าสุดที่ค้าง (triage, in_progress)
  - เพิ่มลิงก์ Dashboard ใน nav bar
- ไม่ทำ:
  - ยังไม่ทำกราฟ/chart (ใช้ตัวเลขก่อน)
  - ยังไม่ทำ report export
